# 配置与使用

## 插件配置

### 模型连接

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 启用模型连接 | 开启 | 允许 MaiBot 调用已授权账号的模型 |
| 允许模型联网搜索 | 关闭 | 将网页搜索工具提供给模型，需账号与模型支持 |
| 使用工具选择参数 | 关闭 | 传递 `tool_choice` 和 `parallel_tool_calls`，常规函数工具一直可用 |

### 高级设置

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 宿主 WebUI 地址 | `http://127.0.0.1:8001` | 自动添加模型使用的原生配置接口；远程填写目标 Bot 的代理地址 |
| WebUI 登录密码 | 留空 | 同机读取宿主凭据，远程填写登录密码 |
| 授权等待时间 | 600 秒 | 给浏览器登录和粘贴回调地址留出的时间 |
| 模型请求超时 | 240 秒 | 单次模型请求的总等待时间 |

配置版本由插件维护。账号凭据保存在插件数据目录，配置表单保存功能开关、宿主连接信息和等待时间。

## 账号与模型页面

**连接账号**：点击登录后打开链接，在 ChatGPT 页面完成授权，再粘贴最后跳转的地址。页面刷新后会继续显示正在进行的授权；插件重启后重新开始即可。

**添加另一个账号**：发起新的账号注册，已有账号继续保留。成功后新账号成为当前账号。列表中可切换回来。

**退出账号**：撤销授权并清除本机令牌。若远程服务暂时不可用，按页面提示在 ChatGPT 用量设置中断开应用。已签发的客户端编号会保留，方便再次登录。

**测试模型**：直接调用所选模型，显示回复、测试时间与耗时。测试会产生模型用量，结果保留到下次测试或插件重启。

套餐用量到达上限时，插件会暂停这个账号的后续请求。到 ChatGPT 用量页面确认恢复后，点击“额度恢复后继续”，再测试模型。

## 配置 MaiBot 模型

先读取模型列表，选择模型和推理强度，测试后点击 **添加到 MaiBot**。插件会复用已有的账号服务商；相同模型再次添加时更新推理强度，页面显示“已添加”。

然后在 **分配任务** 中选择已添加的模型。每个任务旁边显示当前使用的模型，勾选后点击 **应用到选中任务**。选中任务的模型列表会替换为所选模型；温度、超时等任务参数以及其他任务继续沿用现有配置。图片理解请选择支持图片输入的模型。

这两步分别保存：添加模型后可以暂时保留现有任务。保存使用 MaiBot 原生配置接口，由宿主校验并热重载。页面会显示保存结果；若提示“已保存但热重载失败”，请查看宿主日志并重启对应 Bot。

### 推理强度

默认选择 **模型默认**，请求中省略 `reasoning.effort`。其他档位按所选值传递，实际支持范围取决于账号与模型，建议先测试。设置保存在该模型的 `extra_params.reasoning.effort` 中，共用这个模型的任务会使用相同强度。

测试使用页面当前选择。修改后点击 **保存推理强度**，实际聊天才会采用新值。选择默认并保存，会清除这个模型已有的推理强度设置。

### 手动配置

“分配任务”底部仍可生成配置片段，包含所选推理强度。将片段合并到 MaiBot 模型配置，再将模型名加入对应任务即可。

切换 ChatGPT 账号会影响所有使用本插件的模型任务，请确认新账号能使用任务中配置的模型。

生成片段中的单价为 0，用于套餐授权场景下的本地统计。实际套餐用量以 ChatGPT 用量页面为准。

## 与其他插件一起使用

通过 MaiBot 原生模型任务调用模型的插件可以继续使用这些任务。工具定义、对话上下文、图片和工具结果由模型适配器转换，结果交回 MaiBot。

MaiWeave 的生活模型可直接选择已配置的相关任务。本插件的“允许模型联网搜索”用于模型回复过程中的搜索；独立的 MaiBot 网页搜索服务仍按宿主配置运行。
